Have two lists of programming languages.
 1. Languages I used for something more than basic test projects.
 2. Languages I explored. Solved some Advent of Code or Project Euler
    problem in.
    
# Languages I Used

## [Kotlin](https://kotlinlang.org)

It is my primary language at work. Use it to write backend code on the JVM. Makes coding for JVM acceptable.

## [Lua](https://www.lua.org/)

Can't really avoid it since it used for configuring so many of the tools I use from my terminal, [WezTerm](https://wezterm.org), to [Typst](https://typst.app) that I use for creating documents.

## [OCaml](https://ocaml.org)

Used to write personal CLI tools. Mostly explored OCaml 5.

# Languages I Explored 

I think that there are more new languages being created because of AI
than before. Most of the languages I explored with were related to effects.

## [Koka](https://koka-lang.github.io/koka/doc/index.html)

Ever since I found Koka, I have been fascinated by it. It is the language I have enjoyed writing code in the most. I would love to explore effect types and effect handlers.

## [Prism](https://sdiehl.github.io/prism/)
Just like Koka but with ML syntax is how I ended up exploring it.

## [Gossamer](https://gossamer-lang.org/)
Initially, I played with it because I thought it was a functional Go.
Loved generating single binary and the rich standard library. However,
I didn't enjoy the Rust inspired syntax as much. Got distracted by Prism.

# Languages I Looked At

Didn't really do anything with these languages, but were interesting in
some ways. May be I will explore these in future.

## [Jo](https://jo-lang.org/)

Found this language when I was looking for a statically typed language
that generates Python code. Found the idea of generating Python and Ruby
code interesting. What was even more interesting was compile time sandboxing.

## [Cangjie](https://cangjie-lang.cn/en)

Cangjie popped up in my list because of Kotlin and effect handlers.
It is a language from Huawei. Guess it is their primary language
for HarmonyOS. It is interesting, but not different enough from
other languages for me to explore more. Watched this [video](https://www.youtube.com/watch?v=ujpl5_TmAaE)
and then wrote some example code.


# Others

Played around with [Janet](https://janet-lang.org/index.html) as my potential go to scripting language.
I looked into [Nelua](https://nelua.io/) as statically typed Lua. However,
didn't exlpore a lot because most of my Lua code is a configuration language.
Thought [Grain](https://grain-lang.org) would be fun to play with WASM. Didn't
really do anything with it. [Gren](https://gren-lang.org/) was an option for
writing browser apps and CLI tools. Saw it as Elm for browser, CLI and server.

I am interested in effects since I got introduced to them in Koka. As a
result I played with [Eff](https://www.eff-lang.org/) and
[Effekt](https://effekt-lang.org/).

 This also let me to
[Osprey](https://www.ospreylang.dev/) Not only does it have effects, it
also has two syntax - Python or ML. This is really interesting. Another interesting
aspect is how you can target GPU or CPU.
